- [Seven native page renders / رندر هفت صفحهٔ بومی](UI-Test-Report.json)

The reports are sanitized public summaries, tied to the published executable SHA-256. Raw local paths and user inventories are not included. These tests are not exhaustive certification; see the safety report's `Gaps` and [SECURITY.md](../SECURITY.md).

گزارش‌ها خلاصهٔ عمومی و بدون مسیر خصوصی‌اند و به هش فایل اجرایی اشاره دارند. هیچ فایل واقعی کاربر در آزمون‌ها پاک نشده است. محدودیت‌ها در `Gaps` گزارش ایمنی و راهنمای امنیت آمده‌اند.
